PROJETO DESENVOLVIDO DURANTE CURSO DO "REI DO CÓDIGO"

O projeto é uma página web desenvolvida com a estrutura simples do HTML, CSS e buscando animações através do JavaScript. Esse foi um projeto feito a partir de algumas aulas da empresa Rei Do Código.
Adquiri o curso para dar os primeiros passos no desenvolvimento WEB e entender melhor sobre as práticas, através de um programador experiente.

Aprendizado técnico do projeto:
- Boas práticas de programação;
- Estruturação de HTML próximo da realidade do mercado;
- Elementos mais avançados do CSS;
- Animações utilizando bibliotecas externas do JavaScript.

Foi um grande projeto  para aumentar, especialmente, o ânimo durante os estudos. Tentei aprender  ao máximo com que estava sendo passado e, hoje, consigo colocar em prática a  maioria dos itens de forma independente.
É sempre especial conseguir ver algum resultado enquanto tenta desenvolver suas habilidades.
